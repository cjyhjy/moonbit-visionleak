三种模式最终身份和见证一致。5000图应检配对6,249,992，选中队列虽已完成，仍为近似覆盖、总体complete:false/exit2。没有把COCO未标注候选计作真实污染发现。5000图缓存逻辑载荷471,683,330字节，文件系统分配529,612,800字节；主进程采样/高水位、ORB及索引子进程指标分别报告，不能相加冒充进程树硬隔离。

冷提取worker请求往返24,704ms，几何worker请求往返47,800ms；阶段墙钟另含宿主准备、校验、缓存与IPC。热运行两项均为0；主机仍需读图校验。单次探索性运行没有统计性能保证，也不是纯CPU剖析。

完整原始证据见../plan-0.9.0/coco-full-resolution-capacity-summary.json和对应100/1000/5000目录。该试验源码07e63417早于本地版本号调整；runtime-parity.json记录关键Core/ORB文件相同。full-warm-replay-verification.json另验证实际0.9.0热重放，所有身份/见证相同、零新增提取和方向检查。后续仅修改了打包过滤及其测试，当前两端完整CI已重新通过。
