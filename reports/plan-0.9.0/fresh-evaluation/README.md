# 新来源受控评测与描述子检索主检验

原始来源清单、API响应、排除清单和保留集冻结位于 ../../../research/new-source-0.9.0/。本目录 summary.json 为汇总；两个分区的完整报告、逐变换漏检及合成参考均单独归档。来源原图（规范化PNG）按摘要保存在研究目录，变换图可按冻结脚本重建。实际运行产生的工作目录位于 .cache/orb-090-fresh-development 与 .cache/orb-090-fresh-holdout。

## 设计与隔离

48个元数据先行选择的文件来源，24开发/24保留，每个分区12个主题家族、每家族2个来源，包含重复纹理、建筑与同类场景主题。主题标签来自API查询，不构成人工语义难负例标注。历史五份来源清单去重后66个来源；new-source-lineage.json独立检查48新文件与历史以及新文件之间的ID、原始/保存字节摘要、上游SHA-1与128px规范化像素；均未发现重合，dHash<=6的待裁决近邻也为零。此检查不能排除所有裁切、变形复用。

每源生成6个查询：原样副本、JPEG45、两处独立58..86%尺寸随机裁切、水印、截图边框。总计每分区168图/144查询。为遵守穷举工作预算，分6批，每批含所有24个原图及24个查询。合成参考严格检查跨集合关系总数3456、重复图像记录一致及每批报告身份/完成度；它是完整关系的复合参考，不是一次大规模审计。

## 检索配置与判定

固定随机bit投影的描述子桶投票，每个查询描述子对每张图最多一票；对称top-k并集，排除Core已有配对。预先声明12/16/20/24 bits、4/8表及k=1/5/10/25，共8组索引配置/32工作点；开发集按预设规则选择24 bits/4表/top-1。开发12-bit配置的漏召回保留在development/lsh-grid/，没有隐去失败工作点。

在下载或查看保留图片前，freeze.json绑定了选择、参数及22份实现/配置文件。保留集仅以24/4/top-1为主检验，不重新选择参数；工具同时输出的其他k值仅为次要结果。主检验达到预设观察值门槛（参考正例召回>=99%、配对削减>=10倍）。71/71对应的配对Wilson描述区间下界约94.87%，且同源查询相关；不能据此声称总体召回率以95%置信度超过99%。

开发索引构建/查询约43/184ms，保留约47/152ms；进程RSS高水位约129/169MiB，包含载入与索引等开销。这些是单次探索性测量；索引计时不含缓存加载、特征提取和几何验证，配对削减23.5倍不等于端到端加速23.5倍。研究原型有200000描述子上限与构建/查询阶段采样RSS护栏，不是已验证的5000图生产索引。

## 可复现性与边界

冻结实现的字节副本位于frozen-implementation/，各文件摘要记录在freeze.json。后续产品开发可能改变工作树；重放保留结果应在隔离副本中还原这些文件及其固定依赖，保留原来源清单/规范化图片与生成规则，不覆盖当前工作区。生成器、完整报告与合成参考支持独立检查配对覆盖及漏检。

开发图像中有一张Poly Haven鹅卵石normal map（137334104），因此本队列是新来源图像，不是纯自然照片集。所有输入在看到结果后均保留；开发contact.png仅用于展示来源质量，无真人复核结论。人工审定的难负例、自然污染、真人耗时、大规模完整配对与产品检索集成仍未完成。
