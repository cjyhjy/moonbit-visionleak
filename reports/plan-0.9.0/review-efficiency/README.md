# 复核工作流功能验收

实现批量复核（每批最多200对）、当前可见队列选择、保留备注、整批撤销，以及按共享图像字节摘要和split聚合导航。聚合只改变显示范围，不将一个结论传播到其余候选。

跨次复核使用独立的 `visionleak-review-transfer-v1` 迁移包：包含源报告和复核记录，先校验双方报告身份和内容/证据绑定，预览后手动应用。要求图片字节/规范化像素、split、算法相关字段、适用profile、完整配对几何见证、显式目标上下文保持一致。图片路径/ID可以变化，缩略图路径不影响结论。多义映射拒绝迁移，已有目标结论保留。每批最多200条，保留来源auditId/pairKey、原备注/时间，支持撤销本批；后续修改会使旧撤销失效。

不同于原有同auditId复核导入，迁移包可能包含完整源报告元数据，导出前用户可在本地查看。当前不导出图片像素，不上传服务器。

功能证据：`tests/review-efficiency.test.mjs` 覆盖原子批量/备注/撤销、改名迁移、内容/split/目标/证据变更拒绝、源身份损坏，以及ORB见证变更。`chunk-and-ambiguity.json` 额外验证201条分200+1批、已有结论保护、两次撤销和多义目标跳过，属于脚本协议测试。

完整生产回归：`../ci-review-mobile/verification.json`，30项检查通过，Node82项零跳过；源码摘要归档后再次核对一致。Chrome结果见browser.json：100对批量标记并撤销、共享图像6对筛选并恢复、单项勾选/详情键盘导航通过。390px初次发现wrapper被flex压窄，修复220px固定卡片容器后刷新复验，卡片可读、队列局部滚动且页面未见横向溢出。原生文件选择器的CUA检查阻塞，被中断，未选择文件；迁移导入/预览/应用/撤销的浏览器全流程仍未验证，不能以Node功能测试替代。测试选择已清空、视口恢复、临时服务已停止。

这些证据验证功能和布局，不证明实际复核提速，也没有新增真人计时。用户当前没有可用复核参与者，真人效率门槛继续保留。
