# 生产检索入口与覆盖合同

这是0.9.0开发中的真实CLI/API接入，默认关闭；尚未发布。summary.json及final-cold/final-warm.json绑定本轮最终源码。既有独立保留集现在只用于已知数据回归，不能称第二次独立新来源检验。

## 已验证

- `--include-orb --include-orb-retrieval --cache CACHE` 启用固定24bit/4表/对称top-1桶投票，然后执行原有几何验证，保留Core证据优先级。
- 168图实际入口以全新缓存提取特征并执行217次几何检查；输出143条证据，其中71条ORB匹配的同方向见证与冻结穷举逐项一致。冷热运行auditId一致。
- 该数据集3384个应检ORB关系只选择并验证144对。因此 `candidateQueueComplete:true`、`exhaustivePairsComplete:false`、整体 `complete:false`，无fail-on命中时退出2。整体不完整是近似覆盖边界，不能脚本只看“队列完成”就声明无污染。
- 报告覆盖、Core校验、工作台和离线HTML都区分近似与穷举。伪造整体complete而无完整穷举会被拒绝。已完成队列而其他Core/输入阶段仍不完整时，工作台也保留其他阶段提示。
- 索引以4份排序压缩的64位hash/图序号数组构建，逐图读取描述子，不常驻所有描述子；独立Node子进程接受整数元数据和描述子，不接收文件路径/执行命令。
- 描述子数量、posting访问、RSS和共享ORB阶段期限分别有护栏。索引候选队列按已完成查询提交进度；部分查询可重做，已完成查询可恢复。候选队列完整后不再启动索引子进程；几何阶段仍按完成方向/输入前缀恢复。

## 索引组件容量

index-capacity.json来自独立Node子进程、每槽800条确定性随机描述子的100/1000/5000阶梯。5000槽为400万描述子，数组分配128000000字节，构建1246ms、查询7445ms，19819285次posting访问，worker采样RSS峰值195002368字节（约186MiB），在256MiB护栏内完成。

这是合成描述子组件测试，未解码图片、运行Core或执行几何验证；不能把它写成5000张真实照片端到端审计。各规模单次测量，与局部测试/GUI工作存在重叠，仅作容量证据，不作稳定加速承诺。

browser.json记录GUI操作观察：桌面和390×844下工作台覆盖提示、ORB71筛选、145/148内点及投影可见。离线页最初长auditId造成横向滚动；修复p的overflow-wrap后，桌面与390px复验通过。当前工具文档没有截图写入文件方法，未伪称保存本地截图。未进行人工复核标记或真人耗时实验。临时本机页面服务在验收后停止；offline.html是最终报告的独立只读快照。
