# 开发与 AI 辅助说明

本项目于 2026-10-22 在用户授权的独立项目目录中实现。使用 Astra ultra 主代理及同配置子代理分工实现 MoonBit 核心、Node 解码/CLI、本地复核界面、邻近项目调研与外部对照。代码、测试、文档和合成样本生成流程均有 AI 辅助，不能当作本人独立创作声明。

开发顺序和证据由文件保留：先读项目 brief 与现有目录；建立输入/输出合同；实现 MoonBit 规范化、SHA-256、dHash 与有预算索引；通过独立平方级 oracle 和标准库 SHA-256 对照；接通真实图片 CLI；测 ImageHash；增加已知误报与漏检样本；完成复核界面、解包验收和交付。所有当轮实测命令、结果及时间见 `reports/verification.json`，benchmark 与评测另有 JSON 原始数据。

局部 MoonBit 工具链来自用户已有工具链，仅复制 bin/lib/include/share 与工具许可证，没有复制凭证、registry 登录状态或全局配置。固定实测版本：moon 0.1.20261012 (748b63c)，moonc v0.10.15+943464bfa。Node/sharp/Python 对照版本均由当轮脚本记录。

本目录没有独立初始化 Git，项目执行聊天没有操作共享 Git 分支或索引；总控已按用户追加授权串行记录真实开发阶段的本地提交。独立公开仓库与远端 CI 由总控另行维护；本项目聊天只读其构建修复作参考，没有操作发布仓库、共享 Git 或参赛表单。原版本的公开 CI 与本轮优化版的本地通过分别记录。

研究来源、版本与声明边界见 `research/comparison.md`；原始项目源码为 MIT。构建产物包含 MoonBit 标准库代码，保留第三方 Apache-2.0 许可和 NOTICE。合成图像来自本项目确定性生成脚本；真实公开样本如使用，另记来源与许可证，不混称自然发生的泄漏。

验收过程中修复了两个集成问题：独立 Python oracle 的 JSON 通道数组需要显式转为 Uint8Array 才能符合严格 JS ABI；本地服务最初误拒绝来自其他页面的正常顶层导航，现仅允许工作台入口页面的浏览器导航，跨站报告/缩略图读取继续拒绝。相关回归与最终运行记录分别保留。

0.2.0 优化轮继续使用 Astra ultra。并行审查核心、复核流程与发布契约；加入 UInt32 距离优化及新旧完整报告对比、内容身份核对、目录创建前的真实路径检查、单步撤销与连续队列。总控同步的固定工具链/CI 修复仅参考独立发布仓库，在本目录整合后重新执行本地验收。新的浏览器证据包含桌面和 390 像素窄屏实际交互；自动化路径文件读取卡顿后改用标准内存文件载荷，未冒称失败的路径输入已通过。

0.3.0 优化轮由当前主代理继续实现，未启动新的并行代理。针对合成评测暴露的水平镜像漏检，新增可选像素反射指纹、双方向普通汉明索引和逐对方向解释；以独立像素/ImageHash 与穷举四距离 oracle 验证。默认模式保留，报告分别绑定配置与内容；新增召回及误报均按固定真值记录。浏览器检查只覆盖本轮实际执行的项目，历史 0.2.0 截图和旧 ZIP 保留。

0.4.0 由主代理继续完成，未启动新子代理。先固定照片来源、许可、原始 SHA-256、协议及 5/5 来源划分；从开发组发现旋转漏检后记录改进决定，冻结检测实现，再检验保留组。照片基准、源码变更、回归和浏览器检查均为 AI 辅助；人工身份与原创声明仍由用户负责。没有根据保留组调参，保留历史基线和新增资源开销。


## 0.5.0 第 0、1 阶段：产品路径与独立 oracle

按负责人采纳的计划，模块名采用 `cjyhjy/visionleak`，大图采用方案 a。报告身份、报告/复核记录规则、CLI 预算与别名规则、评测指标纯计算已迁至 MoonBit；原 JS/Python 对应实现删除，主路径通过编译导出调用。主机 Date.parse、URL 处理、Map 适配和 UI 筛选仍由 JS 负责。流式 SHA-256 和完整源图像素摘要也由 MoonBit 执行。

Python 的 `canonical`、ImageHash、物理图像变换和穷举索引参考保持独立；它们不调用 MoonBit 的像素或距离实现。指标统计是产品核心的一部分，不能再把 MoonBit score 的包装测试称为独立算法 oracle。迁移后的算法与信任边界测试在三个 MoonBit 后端执行，Node 保留 ABI、文件系统、解码、HTTP 和 UI 工作流集成测试。

语言统计采用公开方法的本地字节估计，完整列出测试字节数；仅 dist 和历史编译引擎基线标为 generated，没有隐藏手写源码、Python oracle 或测试。它不是远端 GitHub languages API 的替代证据。阶段执行、未测项与审批边界见 `reports/plan-0.5.0/phase-0.md` 和 `phase-1.md`，不据此声明 Claude 已验收、已经发布或已经提交参赛。
