# 0.7.1：等价检索优化

MIH 查询改用复用的代次标记数组，避免为每次路径成员查询建立 Map。BK 遍历、posting/祖先访问、距离计算、预算计数及返回顺序不变。每次 audit 独立建索引，最多 10000 图像 × 20 窗口，代次不会溢出。

新增永久回归直接对照已发布 0.7.0 产物：144 组完整输出/截断前缀逐字比较，12 组独立穷举，覆盖半径 0/3/4/6/7/8、配对上限、零预算、重复候选与局部见证。所有旧接口和默认设置保持兼容；新运行时摘要会改变新报告 auditId，已有报告仍以其自身引擎摘要验证。

此前冻结的本机核心检索实验得到 1.51 / 1.09 / 1.20 倍中位加速，几何平均 1.255 倍；这不是端到端、Linux/native 或自然数据性能保证。原始记录保留在 `reports/followup-retrieval/`，不重写冻结协议。历史研究脚本需在 0.7.0 源码上运行；日常回归运行 `node --test tests/mih-generation.test.mjs`。

ORB 仍是独立研究候选，将在 0.8.0 进行默认关闭的产品集成。本版本没有新增 ORB 检测能力。

本版本验收与发布状态见 `reports/integration-0.7.1/`；实际远端和发布状态分别记账。
