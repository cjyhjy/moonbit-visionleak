## P1-Q：裁切检测质量实验

- [x] **Q-01 先固定实验协议与停止条件。** 所有看过的照片集（含 photos-v3）归入已知开发/回归数据；按原始来源分区，同源变体不跨区。最多两个原型、每个最多两组预先声明的参数。协议写明随机位置、比例、宽高比、原图配对召回、TP/FP/FN、候选量、时间和峰值内存及接受上限，运行前冻结。
- [x] **Q-02 测量固定窗口替代原型。** 在有硬上限的窗口数量/资源范围内评估覆盖变化，不无限增加窗口或放宽阈值。保留每个漏检和误报；报告原图—裁切配对，不用裁切之间互相匹配替代。
- [x] **Q-03 测量局部特征替代原型。** 评估局部特征及几何一致性路线；仅作为明确命名/version 的研究原型。若采用任何粗筛，单独测量粗筛候选召回，不默认全图相似度能够保住裁切。
- [x] **Q-04 作出继续/停止决定。** 按 Q-01 的预设标准评价两个原型；未达标就记录失败并停止该路线。达标候选需明确证据合同、近似过滤边界、依赖和集成成本；不得直接升级为确定性证据。
- [x] **Q-05 冻结后做新来源验收。〔条件任务〕** 仅在 Q-04 选出值得继续的候选时执行：先冻结算法、参数、源码和协议，再获取未用于调参的来源。分开报告受控变换与自然污染、阶段覆盖、配对召回、候选复核负担和资源消耗。自然污染与真人复核未测时明确记录，不外推准确率保证。
