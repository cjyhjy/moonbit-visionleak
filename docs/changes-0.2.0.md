# VisionLeak 0.2.0 优化记录

本轮在已验收 0.1.0 基线上继续优化，保留原 ZIP 与原验收快照。主要模型为 Astra ultra；没有改动共享 Git 或独立发布仓库。

## 核心计算

验证 dHash 后只打包一次为两个 UInt32；BK-tree 查询、插入及精确证据距离使用 XOR + popcnt。公开 API、64 位指纹协议、阈值、遍历顺序、预算计量与证据等级保持原语义。

360 组阈值、预算、精确桶与碰撞场景的新旧**完整序列化报告逐字一致**。旧编译产物保存在 `research/baselines/visionleak-0.1.0.mjs`，新旧摘要、输入摘要和每次原始计时均在 `reports/core-optimization.json`。运行 `node tests/core-performance.mjs` 可在解包项目中复现。

| 本机合成负载 | 0.1.0 中位耗时 | 0.2.0 中位耗时 | 结论 |
|---|---:|---:|---|
| 1000 个随机指纹，阈值 6 | 226.088 ms | 20.239 ms | 本轮约 11.17 倍 |
| 1000 个密集相同指纹，成对预算 100 | 2.596 ms | 2.693 ms | 无提速结论 |

同进程双方各 3 次预热，10 次交替先后顺序的成对采样，含 JSON 转换；Node v26.7.0、Apple M5 Pro、darwin/arm64。只说明该本机合成索引负载，不表示端到端图像扫描快 11 倍，也不是跨工具比较。

## 正确性与复核流程

- 默认报告和文件导入均重新计算内容摘要，内容变化但沿用旧 auditId 时拒绝加载。新算法明确标识版本，规范化对象键；旧 0.1.0 原顺序算法报告与附加 review 导出仍兼容。内容摘要不是签名。
- 输出目录先解析最近存在的真实祖先，再判断与源数据集是否重叠，避免拒绝符号链接别名输出时已提前在源目录创建子目录。
- 「未复核」筛选下标记后继续下一条；新增下一待复核、单步撤销、J/K/N 导航，分别显示未复核与暂不确定。输入框内不触发导航。
- 桌面 1440×1000 与 390×844 窄屏实测了复核/撤销，检查无横向溢出。窄屏是浏览器视口模拟，不是真手机。

## 构建与交付

从总控维护的独立仓库只读同步了固定工具链下载/校验、Node/Python 版本文件和 GitHub Actions 流程。当前编译器不支持本包 native foreign_library 链接；实际构建并运行 native release **测试可执行文件**，另保留 native debug 验证。

打包版本来自 package.json、lock 与 moon.mod 的一致版本；同版本不同内容的 ZIP 拒绝覆盖。SHA256SUMS 保留旧版条目。缺失 ZIP 会将验收状态改为 failed，避免残留旧 passed；归档及解包版本必须匹配，成功后清理本次解包目录，失败保留排错材料。

本轮没有执行新的 bootstrap 下载；本机使用已有同版本工具链。本地完整源码 CI 与交付门禁均通过；新增优化版远端 CI 未由本聊天触发或确认。

## 验收结果与边界

- MoonBit JS / wasm-gc / native debug：各 9/9；native release：9/9。
- Node：35/35；Python 指标回归：4/4；发布契约：10/10。
- 59 张受控合成 PNG/JPEG 与 ImageHash 对照、96 对索引输出独立参考均通过。
- 检测指标保持：精确 TP27/FP0/FN0；近似 TP67/FP2/FN18。已知平色/渐变误报与裁切/镜像漏检未消失。
- 浏览器验证包括摘要拒绝、复核导入、带复核报告导入、缩略图隔离、连续队列、撤销、刷新恢复与键盘。导出控件已操作，下载文件字节及默认报告缺失空态未单独验收。

准确命令、源摘要和产物摘要见 `reports/verification.json`；最终 ZIP 验收与精确 SHA-256 见包外 `reports/release-verification.json`。本地通过、远端发布与正式参赛受理分别管理。
