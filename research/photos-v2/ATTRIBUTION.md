# New photo sources (0.5.0)

32 Wikimedia Commons file sources in eight landmark scenes; 16 development and 16 new holdout sources. All derivatives of a source and all photographs of a scene remain in one evaluation partition.

Stored files are resized RGB JPEG derivatives, longest side at most 384 px. Download and stored SHA-256 values are separate in sources.json. The original bytes are not redistributed. The old photos-v1 holdout is now a regression set for this release.
